# Sales Dashboard – Data Analyst Internship Task 8

## 📊 Overview
This project is part of a data analyst internship assignment. The objective was to design a simple interactive sales dashboard using Power BI that shows sales performance by product category, region, and month.

---

## 📁 Dataset
- File: `superstore_cleaned.csv`
- Source: Adapted from the classic Superstore dataset
- Key Columns:
  - Order Date (converted to Month-Year format)
  - Region
  - Category
  - Sales

---

## 🛠 Tools Used
- Power BI (for data visualization)
- Python + Pandas (for data cleaning and formatting)

---

## 📌 Visuals Included
1. **Line Chart** – Sales over Month-Year
2. **Bar Chart** – Sales by Region
3. **Donut Chart** – Sales by Category
4. **KPI Card** – Total Sales
5. **Slicer** – Region filter

---

## 🧠 Key Insights
See `insights.txt` for full details. Highlights include:
- Technology category had the highest sales
- Sales peaked in Nov–Dec
- West region consistently led in revenue

- Dashboard Screenshot / PDF export
- Cleaned dataset (`superstore_cleaned.csv`)
- Insights summary (`insights.txt`)
